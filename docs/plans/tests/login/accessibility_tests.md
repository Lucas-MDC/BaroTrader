### Accessibility

<a id="login-a11y-001"></a>
#### LOGIN-A11Y-001: feedback aria-live
Source: Added
Conditions:
- #login-feedback uses aria-live="polite".

<a id="login-a11y-002"></a>
#### LOGIN-A11Y-002: accessible login controls
Source: Added
Conditions:
- Username and password inputs have accessible labels or aria-label values.
- The Login button has a descriptive accessible name.
- Inputs use autocomplete values appropriate for login.

<a id="login-a11y-003"></a>
#### LOGIN-A11Y-003: keyboard navigation
Source: Added
Conditions:
- Inputs and the Login button are reachable via keyboard tab order.
- Focus is visible on interactive elements.
- Validation feedback is perceivable after an invalid submission.
